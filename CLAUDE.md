# Immersa Web

## Obiettivo
Visualizzatore WebXR di spazi. Quest 3 scansiona la stanza → cloud. Su PC (stesso account) si caricano modelli 3D, si posizionano nella stanza, si salva il progetto. Riaperto nel visore, i modelli compaiono nella posizione reale. Target: aziende (macchinari, allestitori). L'utente parla italiano.

## Stack
- TypeScript, three.js (senza framework), WebXR, Vite; Supabase (auth, tabelle `rooms`/`projects`/`reports`, bucket privato `models`); Cloudflare Pages; Resend per le mail. Un'unica app: editor PC + modalità XR nel Quest.
- Modelli: il visore legge solo GLB; su PC si importa qualsiasi formato (glb, gltf+bin+immagini, obj+mtl, fbx, stl, ply, dae, 3mf, step/stp, iges/igs, brep, zip) e `editor/importer.ts` lo converte in GLB (STEP/IGES con `occt-import-js`, WASM solo quando serve; l'originale NON si conserva). Il nome del modello è il file senza estensione, unico nel progetto (`scatola_1`…); `RoomModel.source` = file d'origine; finestra con unità e asse Z/Y; solidi con volume negativo girati da soli; facce multi-materiale riordinate per materiale (`mergeGroups`); un gruppo di mesh nello stesso punto = un solo componente (`primitivesOfOne`, `room/parts.ts`).
- Caricamento: il modello importato sta in memoria (`pending:<n>`, `registerPendingModel` in `cloud/models.ts`) e sale al salvataggio (`uploadPending`). Percorso nel bucket `<utente>/<sha256>.glb` (stesso contenuto = un file); `pruneModels` cancella i file non usati e più vecchi di 24 h (avvio editor, apertura libreria, dopo salvataggi/eliminazioni).
- Pesantezza: sopra 500k triangoli (`HEAVY_TRIANGLES`, letti dall'intestazione con `glbTrianglesOfFile`) o 45 MB (`MAX_FILE_BYTES`, il cloud accetta 50 MB) esce la scheda `askSimplify` ("Semplifica" predefinito / "Mantieni originale"). `editor/simplify.ts` (meshoptimizer, `simplifyGlb`): passate con deviazione crescente (0,01% della diagonale ×1,5 fino al 2%, `ErrorAbsolute`, UV vincolati, normali ricalcolate con `withCreasedNormals` a 35°), vertici non usati tolti, fino a 3 giri col budget ×0,6 se il file resta grande; lavoro in worker (`simplifyWorker.ts`, max 4, una parte ciascuno, dati preparati solo con un worker libero: preparare tutto insieme finiva la memoria); modelli senza indice saldati con tabella hash (`weld`); un file ancora troppo grande non parte (errore con `describeGlb`). Stessa scheda per "Sostituisci…"; in "I miei modelli" il pulsante "Semplifica" (`onSimplifyModel`, `replaceModel(..., keepLook)`, triangoli letti con `glbTrianglesAt` e ricordati in localStorage).
